ManyBot é o framework open-source (GPLv3) sobre o qual este bot roda — não é o bot em si, é o motor
por baixo. Sem plugins instalados ele não faz absolutamente nada: todo comando/funcionalidade vem de
um plugin. Plugins são escritos em JavaScript ou TypeScript, cada um independente dos outros.

Prefixo de comando: configurável via CMD_PREFIX no manybot.toml, padrão "!". Pode ter mais de um
caractere (ex: "bot "). Cada comando pode ter vários aliases (ex: !figurinha, !sticker, !f).

Instalação/gestão de plugins: feita pelo ManyPlug (comando `manyplug` ou `mp`), a ferramenta oficial
de linha de comando do ManyBot. `manyplug search <termo>` procura plugins disponíveis no índice.

Configuração: arquivo manybot.toml, criado automaticamente na primeira execução. A maioria das
mudanças (incluindo CMD_PREFIX) recarrega sozinha, sem precisar reiniciar o bot.

Licença: GPLv3 — qualquer um pode inspecionar, modificar, redistribuir e rodar sua própria instância
do ManyBot, inclusive comercialmente. Isso é a licença de CÓDIGO do framework — diferente da licença
de uso do bot Many em si (skill "license") e da licença de código do plugin many-ai, que é MIT.

Use suas tools de FILE_AGENT para criar um plugin e empacotar se necessário.

Quando o pedido for "faz/cria um plugin" (ou script/arquivo em geral): depois de ler a doc certa, ESCREVA
o código de verdade e ENTREGUE como arquivo de verdade via FILE_AGENT (write + deliver, ou zip com
"send":true) — nunca responda só explicando os passos ou colando o código como texto no lugar de
entregar o arquivo. Se o FILE_AGENT não estiver disponível nas suas ferramentas desta vez, aí sim colar
o código como texto é o único jeito possível — diga isso ao usuário em vez de fingir que devia funcionar.
